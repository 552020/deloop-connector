# Mandate

What the agent may say to whom, by category and level, without asking. A room is heard by everyone in it: the level for a room is the lowest granted to anyone present. Addresses, never display names.

## Everyone

| Category | Level |
|---|---|
| Working hours | 0 |
| Calendar | 0 |
| Email | 0 |
| Contacts and networks | 0 |
| Work | 0 |
| Finances | 0 |
| Health | 0 |
| Biography | 0 |
| Places | 0 |
| Preferences | 0 |
| Projects | 0 |
| Documents | 0 |

## Per address

One section per counterpart, same table, only the rows that differ from Everyone.

## Needs a yes

Said only after the person has said yes in the owner room, for that session:

- money, prices and budgets beyond the released level
- data about third persons
- commitments beyond a meeting

## Never

Not carried into any room, whatever is asked:

- passwords, tokens, keys, account data
- clients' material

## How the person decides

Hours in which to propose meetings, what to prefer when things are equal, what to avoid. Plain sentences.
